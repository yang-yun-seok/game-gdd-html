# 장르별 설계 모듈

장르 라벨보다 실제 플레이 루프에 맞는 모듈만 선택한다. 복합 장르는 최대 세 개를 결합하되, 선택한 문서 프로필과 직접 관련된 항목만 가져온다. 장르 모듈을 이유로 다른 프로필의 섹션을 본문에 추가하지 않는다.

## RPG·성장

- 성장축, 레벨 캡, 해금, 빌드 다양성
- 경험치·강화 비용 곡선과 소프트·하드 캡
- 전투력 상승이 콘텐츠 난이도와 만나는 지점
- 실패 후 회복, 리스펙, 뒤처짐 완화

권장 시각화: 성장 곡선 Line, 빌드 관계 Mermaid.

## 액션·전투

- 입력 수용감, 연속 행동 판정, 피격 정지 체감, 피격 보호 시간
- 이동·공격·피격·사망 상태와 취소 규칙
- 카메라, 조준, 락온, 피드백 우선순위
- PvP라면 지연 상황의 체감·공정성·악용 방지 결과

권장 시각화: 상태 전이, 플레이어 행동·게임 상태 Sequence, 체감 시간 비교 Bar.

## 전략·시뮬레이션

- 자원 생산·소비, 병목, 피드백 루프
- 정보 공개 범위와 의사결정 템포
- AI 규칙, 난이도 조절, 승패 조건
- 세이브·로드와 결정 되돌리기

권장 시각화: 자원 흐름 Mermaid, 생산·소비 Stacked Bar.

## 퍼즐

- 규칙 학습 순서, 힌트, 실패 비용
- 퍼즐 상태 표현과 해답 유일성
- 난이도 축과 콘텐츠 생성 규칙
- 접근성, 색각, 입력 대체

권장 시각화: 학습 곡선, 퍼즐 상태 전이.

## 로그라이크·세션형

- 런 구조, 분기, 위험·보상, 메타 성장
- 빌드 시너지와 중복 방지
- 실패 후 보존·손실 규칙
- 동일 조건 재현 요구, 변주 추적 기준, 콘텐츠 소진 방지

재현 방식은 `개발 협의`로 남긴다.

권장 시각화: 런 Flow, 보상 기대값 Chart.

## 수집형·가챠

- 획득 풀, 등급, 확률, 천장, 중복 처리
- 재화 소스·싱크와 유료·무료 경계
- 정보 공개, 법·플랫폼 요구사항
- 장기 가치, 파워 인플레이션, 복귀 지원

권장 시각화: 누적 획득 확률, 경제 흐름. 모든 확률은 합계와 근거를 검증한다.

## 소셜·협동

- 역할 상호의존, 정보 공유, 핑·채팅
- 매칭, 파티 이탈, 재접속, 보상 정산
- 신고·차단·모더레이션과 안전
- 협동 실패의 책임 귀속과 갈등 완화

권장 시각화: 사용자 행동·게임 상태 Sequence, 파티 상태 전이.

## 경쟁·PvP

- 매칭 기준, MMR, 랭크, 시즌 리셋
- 공정성, 스머핑, 탈주, 치팅 대응
- 승패 보상과 연패 완화
- 관전, 리플레이, 신고, 제재

권장 시각화: 매칭 Flow, 티어 분포, 목표 승률 범위.

## 방치형·자동화

- 시간당 생산, 오프라인 한도, 자동화 해금
- 접속 개입의 가치와 반복 피로
- 성장 속도, 벽, 부스트, 복귀 보상
- 시간 기준의 일관성과 시간 조작 방지 결과

권장 시각화: 시간 대비 성장 Line, 소스·싱크 표.

## 라이브서비스

- 시즌 길이, 콘텐츠 주기, 이벤트 템플릿
- 배틀패스 진척, 캐치업, 복귀 동선
- 운영 설정 변경 요구와 배포 실패 시 복구 기준
- KPI, 알람, 실험, 세그먼트

권장 시각화: 운영 타임라인, 시즌 진척 Line.
